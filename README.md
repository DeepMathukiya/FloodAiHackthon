# FloodPre – Flood Prediction 

## Overview
**FloodPre** is a web-based application designed to predict flood-prone areas and provide real-time flood risk analysis. It leverages machine learning, satellite imagery, and geospatial data to assess flood risk, map flooded regions, and provide early warnings to help mitigate flood-related damages.

The system also includes functionality for **flood mapping**, **masking flooded areas**, and providing **user alerts** to ensure timely responses in case of imminent flood risks.

## Features
- **Flood Prediction**: Uses machine learning models to predict flood-prone regions based on weather, terrain, and drainage data.
- **Flood Mapping**: Maps areas at high risk of flooding and visually marks them for easy identification.
- **Satellite Image Analysis**: Analyzes satellite images to identify and mask flooded regions in real-time.
- **User Alerts**: Sends **early warnings** to users in high-risk areas with actionable insights.
- **Geospatial Data Integration**: Incorporates various data sources (elevation, drainage systems, etc.) to assess flood risk.

## Technologies Used
- **Programming Languages**: Python, JavaScript (for frontend)
- **Machine Learning**: Random Forest, Classification models
- **Data Analysis**: Pandas, Numpy, xarray
- **Web Framework**: Flask/Django for backend, HTML/CSS/JavaScript for frontend
- **Geospatial Data**: GeoJSON, OpenStreetMap
- **Satellite Imagery**: NASA Sentinel-2, MODIS data
- **Visualization**: Leaflet.js, Plotly for interactive maps and charts
